# Project Summary
This project is a web application designed to connect parents with educational institutions like kindergartens and schools. It offers a user-friendly platform with a mobile-first design, allowing users to search for institutions, manage favorites, submit inquiries, and handle reservations. The aim is to enhance parental engagement in children's education through an improved user experience. Recent updates include an improved institution registration form with multiple image URLs, a "Delete all mock data" feature in the admin panel, and enhancements to the admin page's toast notifications.

# Project Module Description
The project consists of several functional modules:
- **Frontend**: Built with React and TypeScript, featuring user interaction pages, an admin management interface, and a password reset page.
- **Backend**: Manages data and API interactions, ensuring smooth functionality for user requests, powered by Supabase.
- **Components**: Reusable UI components for consistent design throughout the application.
- **AuthContext**: Handles user authentication and session management through Supabase, including admin access and user role management.
- **CompareContext**: Manages a comparison state for institutions, allowing users to compare up to three institutions with an auto-hide feature for the comparison bar.

# Technology Stack
- **Frontend**: React, TypeScript, Tailwind CSS, Vite, shadcn/ui
- **Backend**: Supabase, Node.js
- **Database**: Supabase for data storage and management
- **State Management**: React Context and Zustand for user preferences and session management

# Usage
To set up the project, follow these steps:
1. Install dependencies:
   ```bash
   cd app/frontend
   pnpm install
   ```
2. Build the project:
   ```bash
   pnpm run build
   ```
3. Run the application:
   ```bash
   pnpm run start
   ```
